# Pose Studio · 姿态工坊

一个本地运行的 3D 姿势与构图工具，支持火柴人摆姿、镜头调整、几何体管理、姿势检测，以及 3D / OpenPose 点线图导出。

> 这是我出于兴趣做的个人娱乐项目。如果它能帮大家更方便地摆姿势、做构图，我会很高兴。欢迎反馈问题、分享使用体验，也欢迎提出改进建议。

## 下载与使用

前往 [Releases](https://github.com/wangzhuokai0520-commits/pose-studio/releases) 下载 Windows x64 版本，解压整个 ZIP 后双击 `PoseStudio.exe`。

| 版本 | 适用场景 |
| --- | --- |
| lite 轻量版 · 160 MiB | 默认推荐；摆姿、构图和导出可离线使用，首次检测自动下载约 215 MiB 组件 |
| full 完整离线版 · 366 MiB | 预装检测模型与环境，适合离线使用 |
| source 源码包 | 查看实现或本地构建，安装步骤见包内 README 与 DISTRIBUTION |

不需要另装 Node.js、Python、Blender 或 ComfyUI。检测组件从官方源下载，并校验固定版本的 SHA256。发布附件提供 `SHA256SUMS.txt`。

## 已有功能

- 3D 火柴人关节旋转、手脚 IK、姿势预设、镜像、撤销与重做。
- 独立编辑视角与出图镜头，支持透视、正交和横竖画幅。
- 几何体新增、搜索、多选、复制、落地、隐藏、锁定与删除。
- DWPose 单人姿势检测，可直接将本次检测结果预览并映射到火柴人。
- 导入 OpenPose JSON 或本软件导出的标准彩色点线 PNG。
- 三种导出：3D + 2D、仅 3D、仅 2D。3D 包含 GLB、场景 JSON 和渲染 PNG；2D 包含 OpenPose PNG 与 JSON。
- 可选本地角色资产导入；ComfyUI 接口与 WebUI 地址预留。

## 检测结果如何变成火柴人

在「AI」页完成姿势检测，再到「姿态」页点击「使用本次检测结果」，查看预览后点击「应用为火柴人姿势」。不需要先手动下载 JSON 或图片。

单张二维图无法唯一确定深度，应用后仍可用 IK 修正手脚前后关系。检测可能误判遮挡与动漫人物的关节。

## 当前范围

这是早期的单角色静态构图工具。暂无自动防穿模、衣物物理或 Blender 插件。火柴人 GLB 为静态几何，继续编辑姿势请打开场景 JSON。WebUI 目前仅保存连接地址，尚无生图流程。

发行包不含私有高精度角色、ComfyUI / WebUI 程序或生图模型。角色可在本机单独导入。软件本体尚无自动升级源，组件更新按内置兼容清单进行。

目前仅在开发者的 Windows 机器上验证，尚未代码签名。第三方许可证附在软件与源码包中；原创代码暂未选择开源许可证。
